A lightweight portfolio theme built with native WordPress templates and no page-builder dependency.

== Description ==

72HW Portfolio provides a clean front page, responsive project and post cards, a primary menu, custom logo support, featured images, search and archive templates, comments, and accessible focus and skip-link styles.

The front page uses the `[hw72_showcase]` shortcode when the companion 72HW Showcase plugin is active. Without the plugin, it displays published posts instead. The plugin is optional and is not bundled.

== Installation ==

1. Upload the `72hw-portfolio` folder to `/wp-content/themes/`, or install a ZIP of this repository through the WordPress theme uploader.
2. Activate **72HW Portfolio** under Appearance > Themes.
3. Set the site title and description under Settings > General.
4. Add a logo and primary menu under Appearance > Customize or Appearance > Editor, depending on your WordPress version.
5. Optionally install 72HW Showcase and add Showcase Items for the front-page grid.

== Frequently Asked Questions ==

= Does this theme require a page builder? =

No. It uses native PHP templates and one theme stylesheet. There are no external fonts, scripts, frameworks, or page-builder dependencies.

= Is the companion plugin required? =

No. The front page falls back to published posts when the plugin is inactive.
